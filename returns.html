6. Cancellations

An order can be cancelled for a full refund at any point before the supplier dispatches it. Once dispatched, the return process above applies. If the supplier cannot fulfil an item after payment — for example because stock ran out — we cancel that line and refund it in full, and will offer a substitute if you want one.
